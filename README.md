#DESCRIPTION:

The Pharma Sales Analytics Dashboard is an interactive data visualization project developed using Python, Streamlit, Pandas, and Plotly. The dashboard helps analyze pharmaceutical sales data by providing insights into sales performance, customer behavior, product trends, and city-wise revenue analysis.

The project includes KPI monitoring, sales trend analysis, interactive filters, and dynamic visualizations to support better business decision-making. Users can explore the data through an easy-to-use dashboard interface and download filtered datasets for further analysis.

#TECHNOLOGIES USED
- Python
- Streamlit
- Pandas
- Plotly
