# Pharma Sales Analytics Dashboard
Interactive sales analytics dashboard developed using Python, Streamlit, Pandas, and Plotly for analyzing pharmaceutical sales data.
## Features
- Sales Dashboard
- KPI Monitoring
- Sales Trend Analysis
- Top Customers & Products
- City-wise Sales Analysis
- Interactive Filters
- CSV Download Option
## Dataset Files
- Orders.xlsx
- Customers.xlsx
- Products.xlsx
## How to Run
Type this command python -m streamlit run app.py in command prompt
